## App Review Notes (English)

NFC Tools: Read & Write is a utility for reading and writing compatible NDEF NFC tags. No account is required.

For review without physical NFC tags, open the Tools section to explore templates, QR/barcode scanning, logbooks and the tag library. In the Write section, create a record and preview its content. Some features require device capabilities, permissions or specific iOS versions.

For NFC testing, use a compatible writable NDEF tag (for example, an NTAG213/215/216). Choose Read to inspect the tag, or Write to compose a record, then follow the on-screen instructions. Permanent locking operations cannot be reversed. Supported actions vary by tag and device.

Location is requested only for user-initiated location features. The app can use optional external map, geocoding and cloud services, as described in its privacy policy.
